# Bingo reusable sounds feature preview

Preview URL: /previews/Bingo_Reusable_Sounds_Preview.html

This is a separate feature review page, not the Bingo mother HTML. All browser demo accounts are synthetic. Demo sounds/posts are stored only in IndexedDB on that device. No Supabase client or production account is connected.

The HTML embeds the local Python backend source and integration notes. Download server.py from the page, keep it beside the HTML, and run it locally following the displayed instructions. Never expose the synthetic-session backend publicly.

Verified locally: exact and MP3-reencoded duplicate matching, original credit retained, photo+audio MP4 generation, connected frontend publishing, catalog reload and original profile links. Camera recording, representative sound recognition and production integration remain unverified.

Production integration still needs verified Bingo authentication, protected sound records and storage, an audio recognition/encoding worker, immutable attribution and sound_id links on real posts. Live Supabase inspection found no sound table or deployed sound processor. Current Home, composer, Messenger, Cockpit and logo have not been modified by this preview publication.
