Backend package & preview limits

This single HTML includes the connected frontend and the complete local review backend source. The backend must run as a separate process; HTML cannot execute server code.

  1. Download server.py below. Keep it beside this file, named Bingo_Reusable_Sounds_Preview.html.
  2. Install Python 3.11+ and FFmpeg/FFprobe with Chromaprint, H.264 and AAC support.
  3. Run python server.py.
  4. Open http://127.0.0.1:8765/. The frontend automatically connects to the local backend.

Synthetic preview accounts only. Before production approval, connect verified Bingo authentication, production storage/database and a moderated recognition service. No production credentials are included. This feature preview is separate from the main Bingo application. Production sound integration is not enabled.
